## Before opening a pull request

Keep changes focused, explain the user-facing reason for the change, and
include relevant validation. If you are unsure whether an idea fits, opening an
issue first is encouraged.

These terms are a practical starting point, not legal advice. Professional
legal review is recommended before the project is released publicly.
